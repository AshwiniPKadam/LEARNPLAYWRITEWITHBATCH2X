# Learn Playwright with Batch 2X

A hands-on tutorial repository for learning Playwright automation testing with JavaScript.

## Contents

| Chapter | Topic |
|---------|-------|
| **Chapter 01** | Basics - Getting started with JavaScript and Playwright |
| **Chapter 02** | JavaScript Concepts - Variables, identifiers, rules |
| **Chapter 03** | Identifier & Literals - Reference files including VS Code keyboard shortcuts |

## Getting Started

1. Clone the repo
2. Open the folder in VS Code
3. Follow the chapter-wise JavaScript files sequentially

## Prerequisites

- [Node.js](https://nodejs.org/)
- [VS Code](https://code.visualstudio.com/)
